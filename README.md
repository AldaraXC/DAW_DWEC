# Ejercicios de Desarrollo Web en Entorno Cliente - DAW

Este repositorio contiene la colección de ejercicios, prácticas y proyectos desarrollados durante el módulo de **Desarrollo Web en Entorno Cliente** del Grado Superior en Desarrollo de Aplicaciones Web (DAW). 

El objetivo de este repositorio es documentar mi progresión lógica aprendiendo JavaScript.

## 🛠️ Tecnologías y Herramientas
- **Lenguaje:** JavaScript
- **IDE:** Visual Studio Code
- **Control de Versiones:** Git / GitHub

## 📂 Estructura del Repositorio
El código está organizado de forma modular por temas o unidades de aprendizaje:
