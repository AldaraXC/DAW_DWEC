# Enunciado

Vas a necesitar prompt y document.write para realizar la comunicación con el usuario.  No uséis alert. 

    **/Género.** Crea una variable llamada nombre y otra llamada genero.
        - Usando prompt pide valores para ambas variables. El género puede ser hombre, mujer y otros. 
        - Muestra un mensaje en consola que diga: "Hola, [nombre] eres hombre." Si eres hombre:  "Hola, [nombre] eres mujer." y "Hola, [nombre] eres otros."
        - Debes realizarlo con if. 
        - Debes realizar validaciones para evitar errores dentro de lo que hemos visto en las clases online.
    **/Tablas de Dividir.**  Pide al usuario dos números. El primero será el valor que vamos a dividir, el segundo el valor con el que vamos a dividir. 
        - Los números son enteros. 
        - El valor primero por el usuario debe ser mayor que 100 y menor de 1000.
        - El segundo número va a ser mayor de 0 y menor que 100.  Debes evitar bucles infinitos y puede producirse. Arréglalo. 
        - En el caso de que el valor introducido sea incorrecto, debe seguir preguntando al usuario por un valor, hasta que introduzca uno válido.
        - Ahora vas a ir dividiendo y mostrando los cocientes y restos de cada operación hasta que no sea posible con números enteros. Por ejemplo: 100 dividido entre 11 da 9 y el resto es 1. Como no se puede dividir 9 entre 11 ya has terminado. 
        - La salida debe mostrarse con document.write.
        - Debes realizar validaciones para evitar errores dentro de lo que hemos visto en las clases online.
